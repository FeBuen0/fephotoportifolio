Autorize o envio das fotos uma vez neste navegador. Depois, entre com seu usuário e senha.

  1. Abra a autorização no GitHub ↗ usando a conta FeBuen0.
  2. Em Repository access, marque Only select repositories e escolha fephotoportifolio.
  3. Confira Contents: Read and write, escolha a validade e clique em Generate token.
  4. Copie a chave gerada e cole abaixo.

A chave fica criptografada somente neste navegador e é enviada apenas ao GitHub. Em outro navegador, conecte novamente.
